Features

Everything you need, nothing you don't

Tempo packs a serious feature set into a clean, fast app — and every byte of it runs locally on your machine.

Precision clicker

The core, tuned for accuracy and speed.

  • Interval, hold-to-click & burst modes
  • Single to quadruple, any mouse button
  • Fixed point, follow-cursor or multi-point
  • Repeat by count or time · one-tap CPS presets
  • Timing & position randomization to soften the pattern

Multi-point sequences

Click a whole route, not just one spot.

  • Sequential, reverse, random or ping-pong order
  • Per-point button, click style & dwell time
  • Per-point repeat counts
  • On-screen numbered markers
  • Quick-capture a sequence in seconds

Macro record & replay

Capture mouse + keyboard, then play it back.

  • Edit steps, loop, and control speed
  • Countdown, loop delay & live step monitor
  • Pin favourites, add notes, search
  • Export / import individual macros
  • Bind Record & Play to hotkeys for hands-free use

Live statistics

See exactly what Tempo's been doing.

  • Live dashboard: session, current & peak CPS
  • Lifetime totals, records & insights
  • Charts by recent session, day & hour
  • Set a session click goal
  • Searchable history · CSV export

Rebindable hotkeys

Drive everything without touching the window.

  • Global keyboard and mouse-button shortcuts
  • Live conflict detection
  • Works even when Tempo is in the tray
  • Emergency stop & Escape safety
  • Automatic fallback for stubborn keys

Make it yours

38 themes and a UI that follows your taste.

  • 38 colour themes + your own accent colour
  • Optional animated wallpaper backdrops
  • Six languages (auto-matched on first run)
  • System-tray presence · launch at startup
  • Optional offline Live Captions overlay

Install

Download & run in about a minute

Grab the latest release from GitHub, then run it portably or install it. The .NET runtime is bundled, so there's nothing else to download.

Portable · no install

Just run it

One self-contained file · runs in place · settings saved in your AppData · USB-friendly

  1. On the Releases page, download Tempo.exe.
  2. Double-click it — the runtime is built in, nothing else to install.
  3. Done. Your settings, profiles & macros live in your AppData folder.
Installed · no admin

Add to the Start Menu

Start-Menu shortcut · listed in Settings › Apps · clean uninstall

  1. Download Tempo-Setup-<version>.zip and unzip it (keep the files together).
  2. Double-click install.cmd — no administrator rights needed.
  3. Launch Tempo from the Start Menu. Uninstall any time via Settings › Apps.
First-run note. Because Tempo isn't code-signed, Windows may show "Windows protected your PC" / "Unknown publisher." That's normal for a small free app — click More info → Run anyway. Verify your download with certutil -hashfile Tempo.exe SHA256 against the Tempo.exe.sha256 published with each release.
Building from source? Clone the repo and run publish.cmd — it produces a self-contained Tempo.exe and a setup zip with checksums, ready to release.

FAQ

Common questions

Is Tempo really free?

Yes — completely free and open, no account, no ads, no telemetry. It runs entirely on your PC.

Why does Windows say "Unknown publisher"?

Tempo isn't code-signed (certificates are costly for a free app), so SmartScreen shows a caution the first time. Click More info → Run anyway. You can verify your build with certutil -hashfile Tempo.exe SHA256 against the published checksum.

Will it get me banned from a game?

Possibly. Auto-clicking can violate a game's terms of service, and some anti-cheat systems detect it. Use it responsibly — you're responsible for how you use it. Reasonable speeds and the randomization options soften the obvious-robot pattern, but nothing makes it undetectable.

What's a safe clicking speed?

For most uses the low hundreds of CPS is plenty. Very high speeds can trip anti-cheat and stress your PC. Tempo's anti-freeze protection is on by default — leave it on. The CPS presets (10/50/100/200) are good starting points.

Where are my settings stored?

In %LOCALAPPDATA%\AutoClicker. That folder survives updates and can be backed up or deleted. There's no cloud copy.

What languages does it support?

Six: English, Spanish, French, German, Italian and Portuguese. Tempo matches your Windows display language on first run, and you can change it any time in Settings (it applies after a quick restart).

Does it work on Mac or Linux?

No — Tempo is a Windows app (64-bit Windows 10 or 11). The .NET runtime is built in, so there's nothing else to install.
