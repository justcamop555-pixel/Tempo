The clicker itself

Every control, already built in.

This is the shipping feature set of the Clicker tab — nothing here is planned, it all exists today.

  • Three modes — interval, hold‑to‑click (clicks only while you hold the key) and burst, with single / double / triple clicks and a per‑click hold time.
  • Repeat your way — until stopped, a fixed count, or for a duration with a live "s left" countdown — plus an optional chime + tray notice when a fixed run finishes by itself.
  • Anywhere on screen — click at the cursor, a fixed point, or a multi‑point list; restore the cursor when stopped.
  • Human, if you want — position jitter, interval randomization and a one‑click Humanize preset.
  • 2,000 CPS ceiling — sub‑millisecond intervals above 1,000, a clicks‑per‑minute readout, and Anti‑Freeze protection that throttles before your PC chokes.
  • Profiles & safety — save and duplicate full setups, start‑delay countdown, pause/resume, and a global emergency stop.
Macro recorder

Do it once. Tempo does it forever.

Press record, perform the task, press stop — name it, pin it, play it back.

  • Playback timing carries fractional milliseconds between steps, so a 10× run is exactly 10× — measured, not hoped.
  • Loop a fixed number of times or forever, with a delay between loops and an estimated time-remaining readout.
  • Edit, rename (F2), duplicate, export and import macros — or merge several into one.

Privacy & safety

Runs entirely on your PC.

Your clicks, macros, profiles and statistics never leave your computer. The only network use is the optional update check against GitHub — and you can turn that off.

No accounts, no telemetry

There is nothing to sign into and nothing phones home. Settings live in a plain local folder you can open from the app.

Verified updates

In-app updates are checked against a published SHA-256 checksum before they replace anything — a corrupted or tampered download is rejected.

Open releases

Every version, changelog and file is public on GitHub. Build it yourself or grab the release — same code either way.

Accessibility

A Live Captions key for voice chat.

If you're deaf or hard of hearing, voice chat and team callouts can be hard to follow. Tempo gives you a single hotkey to flip on Windows Live Captions — which transcribes all PC audio in real time, over any app, including fullscreen games.

  • Bind Toggle Live Captions to any key on the Keybinds tab — turn captions on and off without leaving your game.
  • Windows Live Captions captions everything you hear: game voice chat, Discord, livestream audio.
  • It's built into Windows 11 (22H2+), free, and runs offline after a one-time language download.

Honest note: Tempo doesn't transcribe speech itself — accurate, real-time captioning needs the operating system's built-in speech engine, which already does this far better than a bundled tool could. Tempo simply puts that system on your hotkey.

Get Tempo

Two ways in. Both take a minute.

Installer RECOMMENDED

  1. Download Tempo-Setup-<version>.zip from the latest release.
  2. Unzip it and run install.cmd — no administrator rights needed.
  3. Launch Tempo from the Start Menu. Uninstall any time from Settings → Apps.

Portable

  1. Download the single Tempo.exe from the latest release.
  2. Put it anywhere and run it. That's the whole install.
  3. No .NET to install either way — everything is bundled.

Windows may show "Unknown publisher." That's because the app isn't code-signed — click More info → Run anyway. It's safe, and the SHA-256 checksum on each release lets you verify the file yourself.

Questions

      
Asked before you asked.

      

        
Can I use it in games?
          
Technically yes — honestly, check first. Many online games ban auto-clickers, and at high speeds the input is obviously automated. Tempo even warns you about this inside the app before unlocking advanced speeds. Single-player and idle games are the usual home for it.

        
Does 2,000 CPS really land 2,000 clicks?
          
Tempo schedules clicks at up to 2,000 per second using sub-millisecond intervals. Whether every one registers depends on Windows and the target app — much above ~1,000/s the OS may coalesce input. The app tells you this too; no magic claimed.

        
Which Windows versions work?
          
Windows 10 (1607+) and Windows 11, 64-bit. The app is built on .NET 8 with everything bundled into the download, so there's nothing else to install.

        
I'm deaf — can Tempo caption game voice chat?
          
Tempo adds a hotkey that toggles Windows Live Captions, which transcribes all audio on your PC in real time and floats a caption bar over any app, including fullscreen games — so it covers game voice chat, Discord and livestream audio. Bind "Toggle Live Captions" on the Keybinds tab, then press it in-game. Live Captions is built into Windows 11 (22H2+), free, and works offline after a one-time language-pack download. Tempo doesn't do the transcription itself: real-time speech-to-text needs the OS-level speech engine, which does it far better than a bundled tool could, and can't cleanly separate voices from a game's mixed audio anyway.

        
How do I uninstall it?
          
If you used the installer: Settings → Apps → Tempo → Uninstall (or run uninstall.cmd). It removes the shortcuts, the Apps entry and the program files, and asks whether to keep your saved settings. Portable users just delete the exe.
