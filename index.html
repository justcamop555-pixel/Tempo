Install

Two ways to run

Build Tempo once with publish.cmd, then run it portably or install it — both work, it’s your call.

Portable · no install

Build, then run

Runs in place · no install needed · settings saved in your AppData · USB-friendly

  1. Run publish.cmd.
  2. Open bin\publish\<rid>\, or unzip Tempo-Setup-<version>.zip anywhere.
  3. Double-click Tempo.exe. That’s it — settings live beside it.
Installed · no admin needed

Build, then install

Start Menu shortcut · listed in Settings › Apps · clean uninstall

  1. Open the project folder and run publish.cmd. It builds Tempo into bin\publish\<rid>\ (for example bin\publish\win-x64\).
  2. Double-click install.cmd.
  3. Launch Tempo from the Start Menu. Done.
First-run note. Because Tempo isn't code-signed, Windows may show "Windows protected your PC" or "Unknown publisher." This is normal for small indie apps — click More info → Run anyway. Want to be sure your build is genuine? Run certutil -hashfile Tempo.exe SHA256 and compare it to the Tempo.exe.sha256 file next to it.
Get started

First steps & friendly advice

The fastest path to something useful, plus a couple of tips so it behaves well.

Click in two clicks

Open the Clicker tab, set your speed, choose a button, and press F6 to start or stop. That's the whole loop.

Pick a comfortable speed

Very high CPS can trip game anti-cheat and stress your PC. The low hundreds is plenty for most uses — and keep anti-freeze on.

Choose a safe hotkey

Bind start/stop to a key or mouse button you won't hit by accident. Tempo warns you if a combo clashes with another action.

Save it as a profile

Keep a "fast game" preset and a "slow form-filling" preset and switch between them in one click.

Features

More than a basic clicker

Everything you'd expect, plus the extras that make repetitive work painless — all on your PC, nothing in the cloud.

Clicker

Interval, hold-to-click, and burst modes. Any button, single to quadruple, fixed point or follow-cursor, repeat by count or time, with timing randomization.

Multi-Point

Click a sequence of points — in order, reversed, random, or ping-pong — each with its own button, click style, dwell, and repeat.

Macros

Record and replay mouse and keyboard actions. Loop, control speed, pin favorites, add notes, search, and export or import individual macros.

Statistics

A live dashboard: lifetime totals, records, insights like streaks and busiest hour, charts, a session goal, searchable history, and CSV export.

Rebindable hotkeys

Global shortcuts using keyboard and mouse buttons, with live conflict detection so two actions never fight over the same key.

Make it yours

38 themes, a custom accent colour, optional animated backdrops, six languages, a system-tray presence, and launch-at-startup.

FAQ

Common questions

Is Tempo really free?

Yes — completely free, no account, no ads, no telemetry. It runs entirely on your PC.

Why does Windows say "Unknown publisher"?

Tempo isn't code-signed (signing certificates are costly for a free app), so Windows SmartScreen shows a caution the first time. Click More info → Run anyway. You can verify your build with certutil -hashfile Tempo.exe SHA256 against the Tempo.exe.sha256 file next to it.

Will it get me banned from a game?

Possibly. Auto-clicking can violate a game's or app's terms of service, and some anti-cheat systems detect it. Use it responsibly — you're responsible for how you use it. Keeping speeds reasonable and using the randomization options reduces the obvious-robot pattern, but nothing makes it undetectable.

What's a safe clicking speed?

For most uses the low hundreds of CPS is plenty. Very high speeds can trip anti-cheat and stress your PC. Tempo's anti-freeze protection is on by default — leave it on.

Where are my settings and macros stored?

In %LOCALAPPDATA%\AutoClicker. That folder has a README explaining each file, survives updates, and can be backed up or deleted. There's no cloud copy.

Do the live captions match Windows 11's?

No. Tempo's optional offline captions use a small on-device model — handy, but a short delay and the occasional misheard word are inherent. For the most accurate, lowest-delay captions, Windows 11 Live Captions is the better choice, and Tempo can launch it for you.

What languages does Tempo support?

Six: English, Spanish, French, German, Italian and Portuguese. Tempo matches your Windows display language on first run, and you can change it any time in Settings (it applies after a quick restart).

Does it work on Mac or Linux?

No — Tempo is a Windows app (64-bit Windows 10 or 11). The .NET runtime is built in, so there's nothing else to install.
