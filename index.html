· Private by design

Yours, and only yours

Your clicks, macros, profiles, statistics, settings and captions stay on your PC. There is no sign-up, no tracking and no analytics. Tempo goes online only for the four things below — the same list it shows at the foot of its Settings — and each can be switched off or simply left unused.

Update check
Asks GitHub whether a newer version is out — when Tempo starts, and again while it stays open. Switch it off with Check for updates in Behaviour.
Release check
Compares a new release with the copy GitHub published, once per version; test builds never ask. Switch it off with Check that Tempo hasn't been tampered with in Data & Backup.
When you use them
Downloading an update you chose or a speech model (from Hugging Face), setting a logo from a web address, and the Roblox account manager, which signs in through your own browser, checks sessions and launches games through Roblox. With the Accounts tab off, Tempo never contacts Roblox.
Local API
Off unless you turn it on. It answers only programs on this PC — nothing on your network or the internet can reach it.

· FAQ

Common questions

Is Tempo really free?+

Yes — free, with no account, no ads and no telemetry, and it runs entirely on your PC. It is source-available: most of its code is public on GitHub for anyone to read.

Why does Windows say "Unknown publisher"?+

Tempo isn't code-signed (certificates are costly for a free app), so SmartScreen shows a caution the first time. Click More info → Run anyway. You can verify your build with certutil -hashfile Tempo.exe SHA256 against the SHA-256 GitHub lists beside Tempo.exe on the release page — its first 16 characters are the Official ID Tempo shows in About.

Does Tempo go online?+

Only for what is listed under Private by design: the update check and the release check, each with its own switch, plus a speech model, a logo address or the Roblox account manager when you use them. Nothing about your clicks, macros, profiles or captions is ever sent.

Do the hotkeys work while I'm in a game?+

Yes. They are global, so they work while Tempo is minimised or in the tray, and since 1.0.323 they also fire while you hold Shift or Ctrl — F6 still works while you sprint or crouch. Keys that type a character (letters, digits, arrows, Enter) still need their exact combination.

Why did Discord say I was playing “Tempo”?+

Discord's game detection takes any program called Tempo.exe for a Steam game of that name. Since 1.0.323 an installed Tempo runs as TempoClicker.exe and is no longer mistaken for it; a portable copy can simply be renamed.

Will it get me banned from a game?+

Possibly. Auto-clicking can violate a game's terms of service, and some anti-cheat systems detect it. Use it responsibly — you're responsible for how you use it. Reasonable speeds and the randomization options soften the obvious-robot pattern, but nothing makes it undetectable.

What's a safe clicking speed?+

For most uses the low hundreds of CPS is plenty. Very high speeds can trip anti-cheat and stress your PC. Tempo's anti-freeze protection is on by default — leave it on. The CPS presets (10 / 50 / 100 / 200) are good starting points.

Where are my settings stored?+

In %LOCALAPPDATA%\AutoClicker. That folder survives updates and can be backed up or deleted. There's no cloud copy.

Does it slow down or freeze my PC at high speeds?+

Tempo has built-in anti-freeze protection: a CPS cap plus a CPU-adaptive throttle that automatically eases off if your system gets busy, so the machine stays responsive. It's on by default.

What languages does it support?+

Six: English, Spanish, French, German, Italian and Portuguese. Tempo matches your Windows display language on first run, and you can change it any time in Settings.

Does it work on Mac or Linux?+

No — Tempo is a Windows app (64-bit Windows 10 or 11). The .NET runtime is built in, so there's nothing else to install.
