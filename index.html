Features

More than a basic clicker

Everything you'd expect, plus the extras that make repetitive work painless — all on your PC, nothing in the cloud.

Clicker

Interval, hold-to-click and burst modes. Any button, single to quadruple, fixed point or follow-cursor, repeat by count or time, with timing randomization to soften the pattern.

Multi-Point

Click a sequence of points — in order, reversed, random or ping-pong — each with its own button, click style, dwell and repeat count.

Macros

Record and replay mouse and keyboard actions. Loop, control speed, pin favourites, add notes, search, and export or import individual macros.

Statistics

A live dashboard: lifetime totals, records, charts, a session goal, searchable history and CSV export — so you can see exactly what Tempo's been doing.

Rebindable hotkeys

Global shortcuts using keyboard and mouse buttons, with live conflict detection so two actions never fight over the same key.

Make it yours

38 themes, a custom accent colour, optional animated backdrops, six languages, a system-tray presence and launch-at-startup.

Install

Download & run

Grab the latest release from GitHub, then run it portably or install it — both work, it's your call. No account, no extra runtime to install.

Portable · no install

Just run it

One self-contained file · runs in place · settings saved in your AppData · USB-friendly

  1. On the Releases page, download Tempo.exe from the latest version.
  2. Double-click Tempo.exe. The .NET runtime is built in, so there's nothing else to install.
  3. That's it — your settings, profiles and macros live in your AppData folder.
Installed · no admin needed

Add to the Start Menu

Start-Menu shortcut · listed in Settings › Apps · clean uninstall

  1. Download Tempo-Setup-<version>.zip from the Releases page and unzip it (keep the files together).
  2. Double-click install.cmd — no administrator rights required.
  3. Launch Tempo from the Start Menu. Uninstall any time from Settings › Apps, or with uninstall.cmd.
First-run note. Because Tempo isn't code-signed, Windows may show "Windows protected your PC" or "Unknown publisher." That's normal for a small free app — click More info → Run anyway. To be sure your download is genuine, run certutil -hashfile Tempo.exe SHA256 and compare it to the Tempo.exe.sha256 published with each release.
Building from source? Clone the repo and run publish.cmd — it produces a self-contained Tempo.exe and a Tempo-Setup-<version>.zip in bin\publish\<rid>\, plus checksums, ready to release.
Get started

First steps & friendly advice

The fastest path to something useful, plus a couple of tips so it behaves well.

Click in two clicks

Open the Clicker tab, set your speed, choose a button, and press F6 to start or stop. That's the whole loop.

Pick a comfortable speed

Very high CPS can trip game anti-cheat and stress your PC. The low hundreds is plenty for most uses — and keep anti-freeze on.

Choose a safe hotkey

Bind start/stop to a key or mouse button you won't hit by accident. Tempo warns you if a combo clashes with another action.

Save it as a profile

Keep a "fast game" preset and a "slow form-filling" preset and switch between them in one click.

FAQ

Common questions

Is Tempo really free?

Yes — completely free, no account, no ads, no telemetry. It runs entirely on your PC.

Why does Windows say "Unknown publisher"?

Tempo isn't code-signed (certificates are costly for a free app), so Windows SmartScreen shows a caution the first time. Click More info → Run anyway. You can verify your build with certutil -hashfile Tempo.exe SHA256 against the Tempo.exe.sha256 published with the release.

Will it get me banned from a game?

Possibly. Auto-clicking can violate a game's or app's terms of service, and some anti-cheat systems detect it. Use it responsibly — you're responsible for how you use it. Reasonable speeds and the randomization options reduce the obvious-robot pattern, but nothing makes it undetectable.

What's a safe clicking speed?

For most uses the low hundreds of CPS is plenty. Very high speeds can trip anti-cheat and stress your PC. Tempo's anti-freeze protection is on by default — leave it on.

Where are my settings and macros stored?

In %LOCALAPPDATA%\AutoClicker. That folder survives updates and can be backed up or deleted. There's no cloud copy.

Do the live captions match Windows 11's?

No. Tempo's optional offline captions use a small on-device model — handy, but with a short delay and the occasional misheard word. For the most accurate, lowest-delay captions, Windows 11 Live Captions is the better choice, and Tempo can launch it for you.

What languages does Tempo support?

Six: English, Spanish, French, German, Italian and Portuguese. Tempo matches your Windows display language on first run, and you can change it any time in Settings (it applies after a quick restart).

Does it work on Mac or Linux?

No — Tempo is a Windows app (64-bit Windows 10 or 11). The .NET runtime is built in, so there's nothing else to install.
