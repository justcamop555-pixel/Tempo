## Tempo 1.0.247

**Clicker, Statistics and Macros — a round of improvements**

### Clicker
- **Auto-press a keyboard key, not just a mouse button.** The button dropdown now has a
  "Keyboard key" option — pick a key (Space, W, a number, F-key…) and Tempo repeats it using
  the same interval, repeat, hold-time and Humanize settings you already use. Great for
  attack/skill/jump spam and AFK anti-idle without recording a macro.
- **Manual Speed now warns when Anti-Freeze will cap it.** If you set a rate above the
  Anti-Freeze "Max CPS", the Target label says so (e.g. "100 CPS — capped to 50 by
  Anti-Freeze") instead of silently clicking slower than the number shown. The "Set exact CPS"
  box's ceiling also follows the slider.
- **Better tooltips.** Fixed the unlock tooltip (it now says the real 2000 CPS ceiling),
  described the Hold and Quadruple options that were missing, and added help to the exact-CPS
  box, the preset buttons and every Anti-Freeze field (these double as screen-reader text).

### Statistics
- **Fixed CSV export.** Big numbers (12,345) and decimals no longer split across columns —
  the export is now correct for spreadsheets and for non-US regional settings.
- **Added JSON export** next to CSV — a clean, structured file that's easy to re-import or
  process and has no formatting pitfalls.
- **"vs yesterday" on the Today card** — a signed trend (e.g. "+3,120 vs yesterday") so a bare
  number becomes an at-a-glance comparison.

### Macros
- **"Keep key/button holds at speed."** New per-macro option so the 2× / 4× speed presets only
  speed up the gaps between actions — a held movement key (WASD) keeps its real length instead
  of shrinking into a tap. Off by default (unchanged behaviour).
- **Merge fixed.** Merging now refreshes the list (so the merged macro's step count is
  correct) and inserts a short gap between the two segments so they don't run into each other.
- **Readable step names.** The Live Monitor and step editor now show "Left ↓", "Key ↑",
  "Move", "Scroll" instead of raw names like "LeftDown"/"KeyUp".
- **Duplicating a macro starts fresh** — a copy no longer inherits the original's play count and
  last-played time (which skewed the "most played" / "newest" sorts).

Cumulative — includes the 1.0.246 timing/caption work, the 1.0.245 game-input fixes and
everything before.
