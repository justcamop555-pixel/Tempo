## Tempo 1.0.254

**The Clicker tab, redesigned — plus two bugs that were quietly changing your settings**

### The redesign
- **A real slider.** Manual Speed (and Window Opacity in Settings) now use a slider Tempo
  draws itself: a dark track, an accent-filled progress section, and a round thumb. The old
  one was Windows' native trackbar, which also happened to be the last control still
  painting light-mode art inside dark themes.
- **The click rate stands out.** The interval hint now reads **≈ 114.3 CPS** in bold accent,
  with "· 35 ms between clicks" muted behind it.
- **Status colour where it belongs.** "Unsaved changes — click Save" uses the accent colour,
  and "Enabled (prevents system freeze)" turns green while anti-freeze is actually on.

No new themes were added — every theme picks these up automatically.

### Two bugs found while testing the redesign

**Scrolling a page could silently change a setting.** Windows delivers the mouse wheel to
whichever control happens to be under the pointer, and combo boxes and number spinners
react by *changing their value*. That meant scrolling the Settings page with the pointer
passing over the Theme box silently switched your theme, and scrolling the Clicker page
over "Millis" silently retuned your click interval. Combo boxes now ignore the wheel while
closed, and spinners only respond to it when focused — in every other case the page just
scrolls, the way a browser treats an unfocused dropdown.

**Your theme or language could reset itself.** The save that runs when Tempo closes read
the theme and language dropdowns and cast their selection index straight into a setting,
with no check for "nothing selected". If a dropdown reported no selection while the window
was being torn down, a negative value went to disk and the setting quietly fell back to the
default the next time you launched. Both are now guarded.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
