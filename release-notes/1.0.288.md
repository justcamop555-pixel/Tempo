## Tempo 1.0.288

**Both caption paths improved: the Windows 11 mirror reacts faster, the own engine's seams got cleaner**

### Windows 11 Live Captions mirror — adaptive polling
When Tempo mirrors Windows' own Live Captions, it reads the Windows bar's text on a
timer. That timer used to tick at a fixed 250 ms regardless of what was happening.
Now it adapts:

- **Words flowing** → polls every **140 ms** (≈100 ms less average delay exactly when
  it matters),
- **Short pause** → eases to 200 ms,
- **Silence** → idles at 350 ms, so Windows' accessibility interface isn't hammered
  for nothing.

Verified live: Windows-engine text relayed promptly with Tempo's speaker labels,
colours and source tag on top.

### Own engine — cleaner seams between chunks
Tempo's own engine listens in overlapping windows, and the JOIN between windows is
where the most visible errors lived: a word at the boundary re-heard as a twisted
repeat. The overlap between consecutive windows widened from 0.6 s to **0.75 s** —
each pass now sees more shared context at every seam, so boundary words come out
whole and the duplicate-stripper has more to match against.

Bonus: because of how the windows advance, the update step actually got slightly
*shorter* (2.2 → 2.05 s) — marginally faster caption updates.

Cost: about 12% more compute per minute of audio — trivial for the GPU engine and
the light models; the automatic too-slow ladder still protects weaker setups.
