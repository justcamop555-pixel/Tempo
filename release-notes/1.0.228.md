## Tempo 1.0.228

**A fresher look: navigation, buttons and the launch screen**
- **Sidebar navigation** — the active tab now has a clean accent **indicator bar** down its left edge, a soft accent-tinted background, and accent-coloured text and icon. The old style filled the whole button with a heavy block of accent; the new one reads lighter and more modern, like the navigation in a polished app.
- **Buttons** — slightly softer rounded corners throughout.
- **Launch / loading screen** — now shows the **Tempo bolt logo**, and is **theme-aware**: it reads your saved theme and accent colour (including a custom accent) so the splash matches the app you're about to open, instead of always being violet.

Cumulative — this build also includes the 1.0.227 smooth-background-scrolling fix and the 1.0.225/226 UI work.

Windows may show "Unknown publisher" because the app isn't code-signed - click More info → Run anyway. It's safe.
