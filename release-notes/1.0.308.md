## Tempo 1.0.308

**A full visual polish pass** — the background image, the loading screen, the tray menu, the status bar, the header and the speed slider all got reworked.

### One seamless background image
Applying a background GIF used to show it as separate, misaligned copies — the
header, the page and the footer each cover-cropped the image against their own
little rectangle, so the crops never lined up. Now it's **one shared image**,
cover-fit against the whole window: the header, sidebar, every page and the
footer each paint only their aligned slice of it, driven by a single animator so
every region shows the same frame. The three confusing Header/Footer/Window
pickers are replaced by one **Background image** picker.

### Adjustable, uniform dimming
The readability overlay is now identical across every area and controlled by a
new **Dim slider** in Settings → Appearance (the dim setting previously did
nothing). Slide from bright to dark and every surface changes together.
Scrolling stays clean — the backdrop is pinned to the viewport, so there's no
ghosting.

### Reworked loading screen
The startup splash was redesigned with a lot more detail:
- a branded row (logo tile with a breathing glow + "Tempo" wordmark + version),
- a tagline,
- a **ticking checklist** of the real startup stages — settings & profiles →
  saved macros → speech-caption engine → audio devices → hotkeys — that check
  off in sequence, with the current step pulsing,
- and a **determinate progress bar with a live percentage** instead of the old
  indeterminate sweep.

### Enchanted tray menu
A branded header banner (the Tempo mark + version), crisp per-item vector icons
in theme hues (instead of mismatched OS emoji), a rounded accent selection with
a left indicator bar, and a state-aware Start/Stop icon (green play ⟷ red stop).

### Enchanted status bar
A themed renderer with a fine accent top hairline and slim separators (no more
dated etched grooves), plus small painted icons on each stat — profile, clicks,
CPS, peak and time — so the bar reads as a compact dashboard.

### Header fix + polish
The mismatched dark box that sat behind "Profile • Default" is gone. It was a
transparent Label that couldn't composite over the owner-drawn header; the
caption is now drawn by the header itself ("Profile •" muted, the profile name
in the accent), and a soft glow sits behind the logo tile.

### Enchanted speed slider
The Manual Speed slider now blooms an accent glow and grows a touch when you
hover, focus or drag it, with a soft drop shadow on the thumb and a gentle glow
under the filled track.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
