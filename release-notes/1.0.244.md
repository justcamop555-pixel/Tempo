## Tempo 1.0.244

**Fixed: wrong page (the Clicker tab) showing after a long minimised macro run + more light-flash cleanup**

Two things people hit after leaving Tempo running a looping macro for hours with the
window minimised:

- **The wrong tab's content after coming back.** If you left Tempo on, say, the Macros
  tab and the window sat minimised for a long time (an AFK grind, with the monitors
  sleeping and waking), you could come back to find the **Clicker page showing on top of
  the tab you were actually on**. Root cause: every monitor wake re-centred *all* pages,
  and that re-centre briefly froze/un-froze painting on the hidden pages too — the un-freeze
  re-showed a hidden page, and the first one (Clicker) then covered the real page. Now the
  paint freeze is only ever applied to the page that's actually on screen, so hidden pages
  stay hidden. Re-centring is also skipped entirely while the window is minimised, and a
  safety check on restore re-hides any stray page just in case.

- **More light flicker gone.** Building on 1.0.243's launch fix:
  - **The number spinners** (the little ▲▼ up/down boxes) drew their native light-grey
    Windows arrows for a frame before the dark ones — now Tempo paints them itself so only
    the dark chevrons ever show.
  - **The tab area** no longer flashes its light Windows tab-body while switching tabs or
    restoring the window — it's cleared to the dark theme colour.
  - **Tooltips** are now dark to match the app instead of the bright system-yellow popup
    that appeared on hover.

- **A finishing macro no longer yanks the window open if you minimised it yourself.** Tempo
  only pops the window back up when *it* minimised the window for the run — not when you
  minimised it on purpose and were doing something else.

Cumulative — includes the 1.0.243 launch flash fix, the 1.0.242 GIF/backdrop scrolling
fixes, per-tab scroll memory (1.0.239) and everything before.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
