## Tempo 1.0.229

**Your background image finally shows through the text — plus tray and multi-point touch-ups**
- **No more boxes over your wallpaper.** When you set a full-window background image, the page labels, section headers and checkboxes used to sit in solid dark boxes that punched holes in the image. They're now transparent, so the wallpaper shows cleanly through the text. Controls inside cards and the input fields stay solid so they're still easy to read, and it's verified ghost-free while scrolling.
- **Tray tooltip tells you the state.** Hover the system-tray icon and it now shows what Tempo is doing — Running, Paused, Playing a macro, Recording, or Idle — along with the active profile, so you can tell whether it's clicking without opening the window.
- **Multi-point Quick Capture points are ready to go.** Points you capture are now enabled by default (just like points you add through the editor), so a freshly captured sequence runs immediately instead of doing nothing until you tick each row.

Cumulative — also includes the 1.0.228 navigation/button/splash redesign and the 1.0.227 smooth-scroll fix.

Windows may show "Unknown publisher" because the app isn't code-signed - click More info → Run anyway. It's safe.
