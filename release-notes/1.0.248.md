## Tempo 1.0.248

**Fix: keyboard-key auto-press with no key set clicked the mouse instead**

1.0.247 added a keyboard auto-presser to the Clicker tab. If you chose "Keyboard key" from
the Button dropdown but hadn't picked a key yet, pressing Start would silently **left-click the
mouse** instead of doing nothing — because the empty key fell through to the normal
mouse-click path.

Now:
- Key mode never falls back to a mouse click. With no key set it simply doesn't act.
- Pressing Start (or your Start hotkey) in key mode with no key chosen shows
  "Choose a key to auto-press first (Click Options → Set key)" instead.

Everything else from 1.0.247 is unchanged (this supersedes it):
- Clicker keyboard-key auto-presser, Anti-Freeze cap warning, tooltip fixes.
- Statistics CSV export fix, JSON export, "vs yesterday" on the Today card.
- Macros "Keep key/button holds at speed", merge fix, readable step names, duplicate resets stats.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
