## Tempo 1.0.220

**Hotfix: fixes the crash introduced in 1.0.219 where scrolling a tab closed Tempo instantly**
- 1.0.219 changed the scroll repaint to redraw child controls synchronously inside the scroll handler. Combined with the existing layout repaint, that could recurse (scroll -> repaint -> layout -> repaint -> ...) and overflow the stack, which closes the app instantly with no error dialog. That is why tabs "crashed Tempo" and why nothing worked after - the process was being killed.
- Both the scroll repaint and the layout repaint now queue a SINGLE deferred full repaint (debounced) instead of repainting synchronously, so the repaint can never re-enter layout in the same call chain. This keeps the 1.0.219 fix for corrupted checkboxes/labels after scrolling, without the crash.
- If you ever see a hard crash again, a report is saved in %LOCALAPPDATA%\AutoClicker\logs - sending it pinpoints the exact cause.

Windows may show "Unknown publisher" because the app isn't code-signed - click More info → Run anyway. It's safe.
