## Tempo 1.0.208

**Windows caption bar now hides the instant captions start; Tempo's bar is back to normal size; splash and welcome notice restored**
- Windows Live Captions bar now hides right away: it used to wait for the first words, so on a silent or blank video (e.g. Windows captioning the mic) it sat visible forever. It now parks off-screen as soon as the window is found - with a safety net that restores it if reading text is impossible on the PC, so you're never left with nothing.
- Tempo's caption bar is normal size again: the small pill from 1.0.207 is removed. The bar stays its usual full size and shows a short "Captions on - listening..." line until real words arrive - no tiny bar, no empty-box flash.
- Splash launch effect restored: the splash now forces itself to paint and come to front the moment it opens, so on a fast machine it can't be told to close before it ever draws.
- Welcome notice restored: a skipped fade-in (when window opacity wasn't usable) silently dropped the queued notice and could leave the window invisible. Every startup path now routes through one guaranteed step that always shows the notice and makes the window visible.

Windows may show "Unknown publisher" because the app isn't code-signed - click More info → Run anyway. It's safe.
