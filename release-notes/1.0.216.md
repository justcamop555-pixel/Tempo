## Tempo 1.0.216

**More reliable Windows Live Captions startup, and the diagnostic now tells you plainly when Windows' accessibility engine is broken (with repair steps)**
- Turning on the Windows caption source is more robust at launch: Tempo now rechecks for the Live Captions window several times over about 6 seconds and re-sends the toggle if needed, instead of giving up after one quick recheck. This helps on a fresh boot or the very first time Live Captions is used, when Windows is slow to start it (and may show a one-time setup prompt).
- The "Diagnose Windows bar" self-test now starts with a clear "UI Automation health: OK / BROKEN" line. If it's broken, it explains in plain language that Windows' accessibility engine is the problem (not Tempo), that no app can read Windows Live Captions until it's repaired, and lists the exact repair steps - plus the option to use Tempo's own offline captions, which don't need it.
- Detection of whether Windows captions are already on uses the LiveCaptions process and Win32 window lookup (not the accessibility API), so the on/off handling stays reliable even when that API is broken.

Reminder: the Windows-mirror caption mode needs Windows' UI Automation working. If your Diagnose shows "UI Automation health: BROKEN", repair it (sfc /scannow, DISM, reboot) or use Tempo's own offline captions.

Windows may show "Unknown publisher" because the app isn't code-signed - click More info → Run anyway. It's safe.
