## Tempo 1.0.245

**Macros now drive WASD / arrow keys in games + Tempo opens on the Clicker tab**

- **Movement keys work in games now.** Recorded WASD / arrow-key macros did nothing in many
  games even though they replayed fine into a normal window. Two causes, both fixed:
  1. **Scan codes.** Tempo was sending keys as *virtual keys*. Games that read the keyboard
     through DirectInput / Raw Input (most of them) only look at hardware **scan codes**, so
     they ignored the input entirely. Tempo now sends every macro key as its real scan code
     (arrows keep their extended-key marker so they aren't mistaken for the numpad), which is
     what games actually respond to.
  2. **Focus.** When playback started, Tempo minimised itself (and its countdown, if you use
     one) which could pull keyboard focus off the game — so the first keystrokes landed on the
     desktop instead. When you start a macro from a hotkey while in a game, Tempo now re-aims
     focus back at that game right before the keys are sent, so nothing is dropped.

- **Tempo opens on the Clicker tab every launch.** It used to reopen on whatever tab you left
  off (e.g. Macros), which was confusing. Clicker is the main tool, so that's where it opens now.

- **Diagnostics.** If Windows blocks Tempo's keystrokes (which happens when a game runs elevated
  / with anti-cheat and Tempo doesn't), Tempo now notes it in the log so it's clear why.

> **If a game still ignores movement:** run that game in **borderless-windowed** mode (not
> exclusive fullscreen), and if it runs with anti-cheat, **run Tempo as administrator**
> (right-click Tempo → Run as administrator) so Windows lets Tempo's input reach it. Also keep
> the macro's playback **speed at 1x** for movement — higher speeds shorten how long each key
> is held, so the character moves less. Some anti-cheat systems block all synthetic input by
> design; that's a limit of any external tool, not just Tempo.

Cumulative — includes the 1.0.244 wrong-page / flicker fixes, the 1.0.243 launch flash fix and
everything before.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
