## Tempo 1.0.285

**Live debug — see exactly what Tempo is doing, in real time**

### The new window
**Settings → Data & Backup → "Live debug…"** opens a real-time view with two halves:

**Live stats** — refreshed every second:

> Captions: ON · Tempo engine · model: base · GPU (Vulkan)
> Engine: last chunk 2280 ms heard in 240 ms · backlog 0.3 s · language auto-detect
> Devices: 🔊 KJW24FVX (NVIDIA High Definition Audio) · 🎙 EMEET SmartCam C60E 4K
> Audio source: Call of Duty · speaker: voice 1 / face 0 (0 faces)
> Session: v1.0.285 · clicker idle

At a glance: which engine is running (CPU or GPU), how fast it really is, whether
audio is backing up, what device it hears through, what app the sound comes from,
and what the speaker detectors currently think.

**Live event stream** — every internal event as it happens: device arrivals and
switches, the audio keep-alive, engine/runtime choice, language locks, model
downgrades, automatic recoveries, caption take-overs. With a text filter, a Pause
tick, and Copy / Save… / Clear buttons.

### Why you'd open it
- "Why are captions slow right now?" → the Engine line answers with numbers.
- "Which GPU/CPU engine am I actually on?" → first line.
- "Something odd happened" → the event stream shows what, when, and what Tempo did
  about it — press **Copy** and paste it into a bug report.

### Private by design
The view reads Tempo's in-memory event ring. Nothing is sent anywhere unless you
press Copy or Save yourself, and the live view works even when "Write a log file to
disk" is switched off.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
