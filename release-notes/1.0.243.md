## Tempo 1.0.243

**No more light "flash" on the labels and buttons at launch**

On startup Tempo faded its window in by ramping the window **opacity** from 0 to 1. A
partly-transparent window is a *layered* window, and combined with the compositing Tempo
uses for its backdrop, that made the labels and buttons briefly flash their **light default
background** before the dark theme showed through — a quick white blink most people saw on
every launch.

- **The window now appears already dark.** It reveals straight at its final opacity instead
  of fading through the layered state, so there's no light flash on the labels, buttons or
  anywhere else — the themed, dark window simply shows up cleanly. (The startup splash still
  gives the smooth load-in beforehand.)
- **Dark from the very first frame.** The form is painted its theme background *before* any
  control is built, so the window can never show a white default behind the controls as it
  comes up. This is theme-correct — light themes start light, dark themes start dark.

Cumulative — includes the GIF/image backdrop &amp; scrolling fixes (1.0.242), per-tab scroll
memory (1.0.239) and everything before.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
