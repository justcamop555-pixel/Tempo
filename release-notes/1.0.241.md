## Tempo 1.0.241

**Clicker &amp; Macros — quality improvements**

Clicker
- **Scroll to set the speed.** Roll the mouse wheel over the Manual Speed slider to
  jump the click rate in useful steps (and it updates live while running) — instead of
  the old one-CPS-per-notch crawl. The page no longer scrolls out from under you while
  you do it.

Macros
- **One-tap playback speed presets.** New **0.5× / 1× / 2× / 4×** buttons in the
  Playback card set the speed instantly, so you don't have to remember the "10 = 1.0×"
  scale or type a number. Added all into the 6 languages.

Both changes are purely additive — nothing about how the clicker or macros already
behave was altered, so existing profiles, macros and shortcuts keep working exactly as
before.

Cumulative — includes the CPS-Test button fix &amp; active-preset highlight (1.0.240),
per-tab scroll memory (1.0.239) and everything before.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
