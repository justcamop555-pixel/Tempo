## Tempo 1.0.252

**Fixed: things flashing "light mode" while you're in a dark theme**

You reported buttons/labels briefly flashing light in dark themes (and no flash in light
mode — because the flash *was* light). Two real sources were still left, and both are gone:

- **Drop-down boxes.** Every combo (Button/Type/Mode, sort, filters…) let Windows paint its
  native **light** button and border first, then painted the dark style over it a moment
  later — so every repaint (switching tabs, hovering, closing the list) flashed light.
  Combos now paint themselves entirely; the light native art never renders at all.
- **List column headers.** The Live Monitor, session history and Multi-Point tables kept
  Windows' light header strip in dark themes — a permanently light band that also flashed
  on every refresh. Headers now use Windows' dark theme, and list & combo-dropdown scroll
  bars are dark too.

This builds on the earlier de-flash work (tab-body erase, number-spinner arrows, the
startup fade) — that set plus this one covers every native light paint we could find in
dark themes. Light themes are unaffected.

No new themes were added — this is purely fixing the existing ones.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
