## Tempo 1.0.295

**Tab can finally be bound · the field shows what it's detecting as you press · Tempo now names your keyboard**

### Tab is bindable at last

It never worked, and not because a key was missing from a list: the capture field was
never even **told** Tab had been pressed. Windows Forms grabs Tab for focus navigation
before a control ever sees it, so pressing Tab in the field simply jumped to the next
one.

Tab is now claimed as real key input — along with Enter, the arrows, Page Up/Down, Home
and End.

Because the field now swallows Tab, it can no longer be used to leave it, so **Esc
leaves the field**. That's the way out for keyboard users.

### A live "detecting" preview while you bind

Click a field and it reads `▸ listening…`. Hold Ctrl+Shift and it updates live to
`Ctrl + Shift + …` — **before** you press the final key.

So the modifiers Tempo has actually detected are visible up front. You catch a Ctrl that
didn't register, or a Shift you didn't mean to be holding, instead of committing a combo
and wondering why it came out wrong.

### Ctrl+Delete and Shift+Backspace are bindable now too

The clear-the-field branch fired on **any** Backspace or Delete — before the capture code
could ever see them — which silently made every modified variant impossible to bind.
Clearing now requires a **bare** Backspace or Delete.

Alt+F4 is passed through as well, so it still closes Tempo rather than binding itself.

### Tempo now names your keyboard

The Keybinds tab and Live Debug show the detected model, layout and key count:

```
⌨  SONiX USB Keyboard · English (United States) · Enhanced (101/102-key), 12 F-keys
```

This matters. When a hotkey "doesn't work on my keyboard", the model and especially the
**layout** are the first two facts anyone needs — the layout is what decides which
physical key produces which virtual key — and Tempo previously couldn't tell you either.

Gaming mice that also register as keyboards (so their macro and media buttons can send
keystrokes) are correctly excluded, so your mouse is never reported as your keyboard.

### Bare keys now warn you

A global hotkey is registered **system-wide**. Bind a bare "A" and the letter A stops
reaching every other program while Tempo runs. A bare Tab would take Tab away from the
entire desktop.

Risky bare keys are now flagged **amber** — distinct from the **red** used when two
actions clash — with a plain explanation of what will happen. Function keys are exempt;
that is what they are for, and why F6 and F8 are the defaults.

It is still allowed. It just can't happen silently anymore.

### Key names read like keys

"Enter", "Backspace", "Page Up", "Left Arrow", "`", "/" — instead of the raw "Return",
"Back", "PageUp", "Oemtilde", "OemQuestion".

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
