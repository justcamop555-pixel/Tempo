## Tempo 1.0.214

**Build fix for 1.0.213 (which failed to compile), plus: Tempo detects when Windows' accessibility API is broken and switches to its own offline captions**
- Fixes a compile error that stopped 1.0.213 from building (a method header was accidentally dropped during editing). 1.0.214 builds cleanly.
- The diagnostic revealed that on the affected PC, Windows' UI Automation core fails to start ("the type initializer for CacheRequest threw an exception"). When that happens, NOTHING can read the Windows Live Captions text - it's a Windows-side fault, not something Tempo's reader can work around.
- Tempo now detects this broken-accessibility condition and, instead of sitting on a blank "listening..." bar forever, automatically switches to its OWN offline caption engine (which doesn't use the Windows accessibility API at all). You're told once, clearly, why it switched.
- If no offline speech model is installed yet, Tempo points you to Settings > Live Captions to add one - that's what lets it caption fully on its own on a PC where the Windows mirror can't work.
- The "Diagnose Windows bar" self-test now also dumps the caption window's text tree, so the exact element holding the words can be identified on PCs where reading does work.

Windows may show "Unknown publisher" because the app isn't code-signed - click More info → Run anyway. It's safe.
