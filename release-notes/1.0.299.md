## Tempo 1.0.299

**Every Tempo window now shows the app icon · the app opens a little quicker**

### The Tempo icon is on every window

The main window and the system-tray entry always showed Tempo's lightning-bolt, but
every pop-up window carried Windows' generic blank icon — in its title bar and in the
Alt-Tab switcher. That meant **Live debug, About, CPS test, Calibrate, Overlay
customise**, the update / download prompts, the macro editors and every other dialog
looked anonymous.

Now they all wear the Tempo icon:

- One call at startup makes Tempo's icon the **default for every window in the app**, so
  nothing is left showing the generic one — including any window added in the future.
- The small fixed dialogs (About, CPS test, the prompts, …) use a window frame that
  Windows deliberately draws **without** a title-bar icon. They've been switched to the
  visually-identical frame that **does** show it, so the icon appears there too — with no
  change to how they behave (still fixed-size, still just a close button).

Verified live: the **CPS-test** and **Live-debug** windows, which previously showed no
title-bar icon at all, now display the Tempo icon, matching the main window.

### Snappier launch

The loading splash now appears the **instant** Tempo starts — before the monitor scan and
the prerequisite check, instead of after them — so there's immediate feedback while the
main window is built behind it. The environment details Tempo writes to its log (monitor
list, refresh rates, memory) used to run **on the critical path** to the window; that now
happens on a background thread, trimming the "wait a moment before it opens" gap.

The honest limit: the biggest part of a *first* launch after downloading a new build is
Windows scanning the fresh, unsigned `.exe` and the one-time self-extract of the bundled
speech engine — that happens before Tempo's own code runs and can't be sped up from
inside the app. Every launch after that is the fast one.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
