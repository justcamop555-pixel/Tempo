## Tempo 1.0.222

**Found the real cause of the checkbox/label corruption: they were set to a transparent background. Fixed.**
- Checkboxes, radio buttons and labels were given Color.Transparent as their background. Transparent child controls over a custom-painted, scrolling panel don't erase their old pixels when the panel repaints - which is exactly why toggling or scrolling left overlapping ghosts and stale text ("overlap = on, text = off"). This was the underlying cause behind the scroll artifacts, separate from the page repaint.
- Every checkbox, radio and label now uses a SOLID background that matches whatever it sits on (the card's surface colour, or the page colour). Solid backgrounds erase cleanly on every repaint, so no more ghosting, stale text or shifted positions when toggling features or scrolling.
- Combined with the WS_EX_COMPOSITED page rendering from 1.0.221, the Settings tab should now stay correct through scrolling, toggling, minimizing and tab switches.

Windows may show "Unknown publisher" because the app isn't code-signed - click More info → Run anyway. It's safe.
