## Tempo 1.0.215

**Caption reading rewritten to work around the broken-accessibility (CacheRequest) fault - so the Windows mirror can read text even on PCs where it failed before**
- After your Windows repair, Tempo now DETECTS the Live Captions window - but reading still failed because of the same "CacheRequest" fault. The cause: Tempo read element properties through the UI Automation ".Current" property bag, which internally builds a CacheRequest - the exact thing that's broken on the affected PC, so every read threw.
- The entire reader (and the diagnostic) has been rewritten to fetch each property individually with GetCurrentPropertyValue instead of ".Current". These calls do NOT go through CacheRequest, so reading can work even while CacheRequest is broken.
- The "Diagnose Windows bar" self-test was rewritten the same way, so it should now actually list the UIA windows and dump the caption text tree instead of failing with the CacheRequest error - the screenshot will confirm whether reading now works.
- Removed dead/duplicate code paths left over from earlier caption attempts.

To verify: turn on Windows Live Captions, then run Settings > Live Captions > "Diagnose Windows bar". If the text tree now shows the caption element, mirroring is working.

Windows may show "Unknown publisher" because the app isn't code-signed - click More info → Run anyway. It's safe.
