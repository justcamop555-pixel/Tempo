## Tempo 1.0.270

**Theme follows Windows light/dark · Humanize becomes a real toggle**

### Match Windows light/dark mode
A new checkbox in **Settings → Appearance → "Match Windows"**. Turn it on and Tempo
follows Windows' own app theme:

- **Dark when Windows is dark, light when Windows is light.**
- **Switches live** — the moment you flip Windows between light and dark (in Windows
  Settings, or automatically on a schedule / Night mode), Tempo re-themes itself with
  no clicks needed.
- While it's on, the manual theme picker is greyed out (Windows is in charge), and a
  **custom accent colour still applies** on top of whichever light/dark base is active.

Verified end-to-end: flipping Windows dark → light → dark switched Tempo's whole
interface each time, instantly, without touching Tempo.

Prefer a specific look? Just pick any theme from the list as before — choosing one
turns "Match Windows" back off automatically.

### Humanize is now a toggle
The **Humanize** button (Clicker → Randomization) makes your clicks look less robotic by
adding a little natural jitter to timing and position. Until now it could only ever turn
that ON — there was no quick way to turn it back off.

Now it's a clean toggle:

- **Press once** → applies sensible natural jitter (still fully adjustable in the
  ± fields beside it).
- **Press again** → clears it, clicks are exact again.
- The button **shows its state**: filled purple with a ✓ when active, a quiet purple
  outline when off. It also stays honest — load a profile or tweak the randomizer fields
  by hand and the button updates to match.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
