## Tempo 1.0.255

**Live Captions now labels who's talking — "Speaker 1:", "Speaker 2:" ...**

When a new person starts talking, Tempo's caption bar now prefixes the line with a
speaker number that goes up each turn:

```
Speaker 1: Welcome to the show today
Speaker 2: Thanks for having me here
Speaker 3: Let us start the discussion
```

The bar shows just the current turn's words after the label, so the "Speaker N:" part
always stays on screen instead of scrolling off the left. It's **on by default** — turn
it off any time in **Settings → Live Captions → "Label speakers"**.

### How it knows a new speaker started
Windows 11 Live Captions doesn't tell any app *who* is speaking — no system does that
without a microphone array. So Tempo does what TV captions do with ">>": it watches the
rhythm of the words. Speech pauses, then new words begin = the next speaker's turn.

Two honest limitations, same as every caption system without voice hardware:
- It can't tell two voices apart. It's detecting *turns*, not identities.
- If one person pauses for a couple of seconds and then keeps going, that counts as a new
  turn. After 30 seconds of silence, numbering restarts at Speaker 1.

### Why it's more reliable than a naive version
Windows Live Captions constantly *reflows* its line — re-capitalising and re-punctuating
earlier words as it grows more confident, even while nobody is speaking. A naive
"the text changed, so someone's talking" check would never see a pause. Tempo instead
times the gaps between the moments the line actually *grows* (gets longer), which reflow
doesn't do — so a real silence is detected even while Windows is fidgeting with the text.
And whatever is already on the Windows caption bar when you switch captions on is excluded,
so the first label reliably starts at Speaker 1 rather than mid-paragraph.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
