## Tempo 1.0.265

**The "already running" message is fixed — right name, version shown, and it actually
shows you the window**

If you launched Tempo while it was already open, the pop-up used to say:

> AutoClicker is already running. Check the system tray for the existing window.

Two things were wrong with that: it used Tempo's **old project name**, and it left you
to go hunting through the tray. Both fixed:

- **Correct name + version.** It now reads *"Tempo 1.0.265 is already running…"* — the
  real build number, in both the title bar and the message. The version is read straight
  from the app, so it can never fall out of sync. (Nice for bug reports: you can always
  see exactly which build you're on.)
- **It surfaces the window for you.** Launching a second copy now brings the already-
  running window to the front — even when Tempo was tucked away in the system tray.
  It works whether the window is minimised, hidden in the tray, or just behind other
  windows.

Verified end-to-end: with Tempo hidden in the tray, launching it again popped its window
straight back to the foreground.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
