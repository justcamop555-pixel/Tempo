## Tempo 1.0.242

**GIF / image backdrop &amp; scrolling fixes**

If you use a full-window wallpaper (Settings › Window image), scrolling is now clean:

- **No more control "overlap" / ghosting over the backdrop.** While you scrolled, the
  pinned wallpaper was repainted a beat late, so a shifted/stale frame flashed on screen
  first — that's what left faint dark boxes and doubled text over the image. The page now
  repaints **immediately and synchronously** on every scroll, so that transient never shows.
- **The animated GIF no longer looks like it "restarts" while scrolling.** Same root cause —
  the wallpaper snapping back after each scroll blit. It now stays put and keeps animating
  smoothly as you scroll.
- **Switching tabs no longer flashes to the top before restoring your scroll.** The
  re-centre + scroll-restore on a tab switch now commits in a **single repaint** (painting
  is frozen during it), so the page appears already at the position you left it — no brief
  jump to (0, 0).

Cumulative — includes per-tab scroll memory (1.0.239) and everything before.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
