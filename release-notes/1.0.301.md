## Tempo 1.0.301

**The AI word fixer respects British English · the AI face analysis paces itself**

### British English is not a spelling mistake
Tempo's mishear fixer repairs words the speech engines get wrong, using Windows'
en-US spell engine. The catch: en-US flags **"colour", "favourite", "realise"** and
friends as errors — and since the American versions are one letter away, the fixer
counted as a "safe fix" what was actually a rewrite of correct British English.

The fixer now gets a second opinion from the **en-GB** engine before touching any
flagged word: valid British spelling → left exactly as heard. On PCs without the
British dictionary installed, behaviour is unchanged.

### Face analysis paces itself to the screen
The face-and-mouth analyser (which face is talking) used to tick at one fixed rate
whether or not a face was even visible. Now:

- **Faces on screen** → analysis runs FASTER (finer mouth-motion sampling, surer
  verdicts, quicker reactions after cuts).
- **No faces for ~5 seconds** → it idles right down, so the analysis cost
  concentrates exactly where it earns its keep.

Verified live in a caption session running on the GPU engine, with the face watcher
active.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
