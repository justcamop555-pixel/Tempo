## Tempo 1.0.227

**Smooth background image while scrolling**
- If you set a full-window background image (Settings → Appearance → Window), it no longer lags or stutters when you scroll a tab. Before, Tempo re-scaled the entire image with high-quality filtering on every repaint, so each scroll tick did expensive work — and with an animated GIF that also disturbed the frame timing, making it look like the animation kept restarting.
- Now the scaled image and its readability scrim are pre-composed into a cached bitmap (rebuilt only when the GIF advances a frame or the window resizes). Scrolling just copies that bitmap, so the wallpaper stays smooth and an animated backdrop holds its place.

Built on the 1.0.225 UI modernization and the 1.0.226 robustness fixes.

Windows may show "Unknown publisher" because the app isn't code-signed - click More info → Run anyway. It's safe.
