## Tempo 1.0.286

**The GPU's headroom now buys you accuracy and speed**

### Beam-search hearing on every model (GPU)
Beam decoding weighs several possible word paths instead of committing to the first
guess — it audibly hears better, at about twice the decode cost. Until now only the
small models could afford it. With the GPU engine measured around **10× faster than
real time**, that cost is pocket change — so with "Try GPU engine" on, **every model
now decodes with beam search, including Large Turbo**: the best model, with its best
hearing, in real time.

Verified live: the log shows *"beam-search decoding enabled for
ggml-large-v3-turbo.bin (GPU headroom)"*, and a long continuous passage captioned to
its final word at full pace with zero too-slow warnings.

### A gentler "too slow" ladder — beam drops first
If a weaker GPU or a suddenly-busy PC can't afford beam after all, Tempo's first
response is now the smallest sacrifice: **simplify decoding (beam off), keep the
model, keep the engine.** Only if it's still too slow do the bigger steps follow
(smaller model → and, for an opted-in GPU, switching back to CPU). Drastic measures
last, not first.

### Even snappier caption updates
The caption cadence now has two earned speed tiers:

- **Fast engines** (light models on a good CPU): ~25% shorter update step.
- **Very fast engines** (typically the GPU): ~40% shorter — captions refresh roughly
  every **1.3 seconds instead of 2.2**, with the same audio context per pass, so the
  accuracy of each pass is unchanged.

Slower setups keep the stable full step. Nothing regresses; speed is only spent
where it has demonstrably been earned.
