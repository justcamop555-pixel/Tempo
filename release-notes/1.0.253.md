## Tempo 1.0.253

**Live Captions fix + noticeably faster scrolling and tab switching**

### Live Captions (Windows 11)
Tempo now decides whether Windows Live Captions is on by looking for the actual caption
**window**, not the LiveCaptions.exe process. Windows keeps that process "warm" even when
the caption bar is toggled off, so Tempo could think captions were already on and skip its
automatic Win+Ctrl+L — and captions never appeared. With window-based detection the
auto-enable works reliably in both directions. (If it still can't start them, the notice
now points you to the one-time Windows setup step.)

### Faster scrolling
Scrolling a page used to force a full synchronous repaint of **every control on every
scroll tick** — machinery that's only needed to keep an animated wallpaper pinned in
place. Without a wallpaper, Tempo now lets Windows do its normal (pixel-perfect) scroll
blit instead, which makes scrolling tall pages like Settings and Statistics dramatically
lighter. Mouse-wheel steps also cover a proper distance per notch now, so you're not
grinding the wheel to move down a page. Wallpaper users keep the exact anti-ghosting
behaviour they had.

### Faster tab opening
Opening the Statistics tab used to recompute every card, chart and the session-history
list **before** the page was allowed to paint — that's the lag you felt "before entering
the tab". The page now appears instantly and the fresh numbers land a frame later.
Non-wallpaper pages also skip a blanket repaint of all their controls on every layout
change, which makes switching between all tabs feel snappier.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
