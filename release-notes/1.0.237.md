## Tempo 1.0.237

**The full visual redesign — rebuilt to match the new look, on every tab**

This is a top-to-bottom restyle of the interface. Because it's built from shared
components, the new look applies across **all tabs** (Clicker, Multi-Point, Macros,
Statistics, Keybinds, Settings):

- **Rounded inputs & dropdowns.** Every number field, dropdown and text box now has
  soft rounded corners with clean stacked ▲▼ chevrons — no more boxy Windows look.
- **Icon buttons.** Action buttons carry icons: **＋ New**, 💾 **Save**, ⧉ **Duplicate**,
  🗑 **Delete**, ▶ **Start**, ■ **Stop**, ⊙ **CPS Test**, and a person on **Humanize**.
- **Colour-coded actions.** New / Set are filled in the accent colour, **Delete** is red,
  and **Humanize** is a distinct violet — so the primary actions read at a glance.
- **Toggle switches.** On/off options like "Notify when a fixed run finishes" are now
  pill toggle switches.
- **Refined card headers.** UPPERCASE, letter-spaced titles next to a rounded, accent-
  tinted icon badge, on rounder cards.
- **Accent values.** The live rate ("Target: **200 CPS**") is highlighted in the accent
  colour, with the detail in a muted tone.
- **Footer hint bar.** A subtle "ⓘ Tip: Press F6 to start/stop · All times in milliseconds"
  line under the Clicker cards.
- **Uppercase field labels** (PROFILE / NAME) and a tidier profile bar.

Everything recolours to whichever of the 30+ themes you've picked, instantly on switch.
New strings are translated into all 6 languages.

Cumulative — includes everything from 1.0.236 and earlier.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
