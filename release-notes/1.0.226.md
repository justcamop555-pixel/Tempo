## Tempo 1.0.226

**Polish on the new flat UI, plus protection against losing your history**
- **High-DPI fix:** the flat drop-down menus now size their rows to the (scaled) font, so list text is no longer cramped or clipped at 125%/150%/200% display scaling. The drop-arrow area scales with it.
- **Steppers stay flat:** the custom up/down arrows on number boxes now re-apply themselves if the control isn't fully ready on first paint, so they can't occasionally show the old native Windows arrows.
- **History safety:** if `sessions.json` is ever corrupted, Tempo now backs it up before writing — so unreadable session history isn't silently overwritten and lost (the same safeguard your settings already had).

Built on the 1.0.225 UI modernization (flat themed checkboxes, radios, combos and steppers) and the 1.0.224 fixes.

Windows may show "Unknown publisher" because the app isn't code-signed - click More info → Run anyway. It's safe.
