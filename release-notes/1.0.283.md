## Tempo 1.0.283

**GPU captions for every GPU brand (opt-in) · Large Turbo measured fully real-time on GPU · new Compact Large model**

### Captions on your graphics card — AMD, Intel and NVIDIA
New in **Settings → Live Captions: "Try GPU engine (experimental · needs restart)"**.
It runs Tempo's speech engine on your graphics card through **Vulkan**, which works
on **AMD and Intel GPUs as well as NVIDIA** — for AMD cards it is the only GPU path
that exists at all.

Measured on real hardware before shipping:

- **Large Turbo — the best model — transcribed 16 seconds of continuous speech in
  sustained real time on the GPU**, final words on screen within seconds, with GPU
  usage spikes confirming the card was doing the inference.
- The caption status line tells you which engine is live:
  "…· GPU engine (Vulkan)" or "…· CPU engine".

It stays **opt-in** because GPU drivers vary wildly between machines. The proven CPU
engine remains the default, is the automatic fallback if the GPU can't initialise,
and there's a **self-healing guard**: if the GPU engine ever can't keep pace with
live audio, Tempo switches the option off by itself, tells you, and returns to the
CPU engine — no stuck-broken state.

### New model: Large Turbo Compact (~575 MB)
The 5-bit compressed build of Large Turbo — near-identical hearing at **a third of
the size** and noticeably less CPU per chunk. It's the pick when the full Large
Turbo lags on a busy or mid-range PC (and a smaller download for limited disks).
Available in the model list with one-click download; verified live.

Bonus: when a too-slow model auto-downgrades, full Large now steps to **Compact
Large first** — keeping its 90+ language hearing — instead of dropping straight to
the English-only Medium.

### AMD users, plainly
- **AMD processor (Ryzen):** always fully supported — the CPU engine uses standard
  instructions every modern CPU has. Nothing to configure.
- **AMD graphics card:** now has its GPU path — tick "Try GPU engine".

The download grows about 6 MB for the bundled GPU engine.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
