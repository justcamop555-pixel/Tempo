## Tempo 1.0.278

**Your choice: show or hide the "♪ YouTube ·" source name on the caption bar**

### The source tag is now optional
The caption bar has shown a "♪ App ·" tag telling you where the audio comes from —
"♪ YouTube ·", "♪ Roblox ·", and the app name on the "♪ Music or sounds" note. Some
people love knowing the source at a glance; others just want the words.

Now it's your call. **Settings → Live Captions → "Show audio source name on the bar
(♪ YouTube ·)"**:

- **Ticked (default)** — captions look exactly as before:
  ♪ YouTube · Speaker 1: hello there…
- **Unticked** — the tag disappears everywhere (both Tempo's own engine and the
  Windows Live Captions mirror), leaving only the words and the coloured speaker
  labels: Speaker 1: hello there…

Takes effect from the next caption line — no restart needed. Verified live in both
positions.

### Heads-up: Windows "Smart App Control" can block Tempo
If Tempo suddenly refuses to start — the process dies instantly, no error, no crash
dialog — check whether **Windows Smart App Control** is switched on (Windows
Security → App & browser control). When enforcing, it silently blocks unsigned apps
like Tempo (and most indie tools). Tempo can't fix or bypass that from inside;
whether to keep it on is your decision — note that once turned off, Windows doesn't
let you re-enable it without a reset.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
