## Tempo 1.0.212

**Caption reading is much more aggressive, and the diagnostic now shows exactly where the words live**
- Tempo now reads the Windows Live Captions text by scanning every text element in the captions window and keeping the longest real line, checking both the element name and its text content. This replaces betting on a single element, which missed the words on some Windows 11 builds - the case where Tempo's bar stayed on "listening..." while Windows clearly showed text.
- The "Diagnose Windows bar" self-test (Settings > Live Captions) now also dumps the caption window's full text tree: every element with its type, name, and text content. If captions still don't appear, run this WHILE Windows is showing live captions and send the screenshot - it shows exactly which element holds the words on your PC so the reader can be pointed straight at it.
- Windows bar hide is unchanged (moved off-screen so its text stays readable; a truly hidden window can stop transcribing, so off-screen is deliberate).

If Tempo's bar still shows no text: open Settings > Live Captions > "Diagnose Windows bar" while real captions are on screen, and share the result.

Windows may show "Unknown publisher" because the app isn't code-signed - click More info → Run anyway. It's safe.
