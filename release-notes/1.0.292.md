## Tempo 1.0.292

**Captions turned OFF now STAY off · the speech-engine error is fixed at the root**

### Turning captions off no longer un-does itself

Switch captions off and, about ten seconds later, they came straight back on — and it
repeated forever.

The watcher that notices you pressing Win+Ctrl+L yourself was checking whether the
Windows caption window **is present**, not whether it had just **appeared**. So after
you turned captions off, it saw the Windows bar still sitting there — very often the
very one Tempo was in the middle of closing — read that as *"the user just turned Live
Captions on"*, and switched Tempo straight back on. Ten seconds later it did it again.

It now fires only on a genuine off→on transition, and an explicit "off" requires the
Windows bar to actually go away before anything can re-arm it.

### "Start automatically for videos and games" is now honoured everywhere

With auto-start switched off, captions could **still** come on by themselves — because
the Windows-Live-Captions watcher above never consulted that setting. It rode on a
different checkbox entirely, so the two features quietly fought each other.

If you have told Tempo not to start captions by itself, it now doesn't. From any
trigger.

### The recurring speech-engine error is fixed — at the root

Every engine restart (a model downgrade, a caption toggle) logged:

```
InvalidOperationException: Collection was modified; enumeration operation may not execute.
   at Whisper.net.WhisperProcessor.OnNewSegment(...)
```

The cause: when captions stopped part-way through a chunk, Tempo **abandoned** the
in-flight transcription. Dropping it made the speech engine run its cleanup — tearing
down its segment handler — **while its own native thread was still using it**.

Tempo now lets the chunk finish and drains it quietly instead of dropping it on the
floor, so the engine is never pulled apart underneath itself.

This was found precisely because of 1.0.291's improved error logging: the stack trace
named the exact line. The same class of race was also hardened in the talking-face
detector, whose tracked-faces list could be cleared while a video frame was still
being analysed on another thread.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
