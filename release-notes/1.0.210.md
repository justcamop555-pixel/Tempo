## Tempo 1.0.210

**Windows captions bar now disappears the moment captions start; smoother launch effect**
- The Windows "Live Captions" bar no longer lingers on screen in its "Ready to show live captions" state. A short, fast hide-enforcer now runs for the first few seconds after captions turn on and repeatedly pushes the Windows bar off-screen, so it's gone immediately instead of waiting for the first transcribed words. Once words are flowing, the normal poll keeps it hidden.
- This targets the case where, with the Windows caption source selected, the Windows bar stayed visible above Tempo's own bar before anyone had spoken. Tempo's bar keeps showing "Captions on - listening..." and fills in with the real words read from Windows.
- Nicer launch: the splash now has a soft accent glow that gently breathes behind the "Tempo" title, and the loading bar sweeps with a blue-to-purple gradient instead of a flat color - a more polished open without changing how fast it loads.

Windows may show "Unknown publisher" because the app isn't code-signed - click More info → Run anyway. It's safe.
