## Tempo 1.0.211

**About box shows the real version; caption mirror reads Windows text more reliably; font picker actually changes the font**
- The About window showed a hardcoded "Version 1.0.206" no matter which build you ran. It now reads the real version straight from the app, so it's always correct after an update.
- Caption mirroring is more reliable: when reading Windows Live Captions, Tempo now checks both the text element's Name and its Text-pattern content, so it catches the words on Windows builds that expose them through either property - the case where the Windows bar showed text but Tempo's bar stayed empty.
- Tempo no longer mirrors Windows' own "Ready to show live captions..." placeholder as if it were a caption; it stays in "listening..." until real words arrive.
- Font picker fixed: choosing a caption font now reliably applies. Fonts without a bold face no longer make the caption fail to draw (Tempo picks a supported style), and the picker only lists fonts actually installed on your PC, so every choice works.

Windows may show "Unknown publisher" because the app isn't code-signed - click More info → Run anyway. It's safe.
