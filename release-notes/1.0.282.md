## Tempo 1.0.282

**The caption status now names its engine — and an honest engineering note**

### See which engine your captions run on
When Tempo's Live Captions start, the status line now names the speech engine along
with the audio device:

> Tempo Live Captions started · system audio · KJW24FVX (NVIDIA High Definition
> Audio) · **CPU engine**

If a future Tempo ships GPU inference, this same line will say so — and until then
it makes clear why a given model is fast or slow on your PC.

### Tried, measured, and not shipped: GPU inference
This release cycle tested two big engine upgrades on real hardware, with timed
caption tests:

- **GPU inference (Vulkan runtime):** processed audio chunks so slowly on the test
  machine that the audio buffer had to drop everything except sentence tails —
  captions showed only the last few words of anything said. Unusable, removed.
- **Newer engine core (1.9.1):** showed no measurable benefit, and its Large Turbo
  run tripped the too-slow auto-downgrade during testing.

Tempo therefore stays on its proven engine (1.8.1) — the exact pipeline behind the
recent big wins (encoder shortcut, beam search, real-time Large Turbo). Both
experiments and their measurements are documented in the project so they aren't
blindly retried.

Everything else in this build is byte-for-byte the proven 1.0.281 caption stack.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
