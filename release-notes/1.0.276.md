## Tempo 1.0.276

**Chinese/Japanese captions wrap correctly · steadier loudness for the speech engine · source tag can't blame caption tools**

### Space-less languages wrap correctly now
The caption bar's colour layout (from 1.0.272) wrapped text at spaces. Chinese and
Japanese don't use spaces — so a whole caption could arrive as one unbreakable "word"
wider than the bar and overflow it. Oversized runs now break into fitting pieces
character-by-character, drawn with no fake gaps inside the run, so CJK captions from
the multilingual models flow across the bar's three lines like any other text. The
same fix covers very long URLs and similar unbroken strings.

(English wrapping re-verified live across multiple lines; the new break-up path runs
through the exact same layout machinery.)

### Steadier loudness for the speech engine
Tempo lifts quiet audio so Whisper can hear it. That gain was recomputed from scratch
for every ~3-second chunk — so between a quiet sentence, a loud effect, and back, the
level Whisper heard could jump up to 8× chunk to chunk, which hurts recognition
consistency. The gain now glides smoothly across chunks, and a peak guard makes sure
a loud chunk arriving right after quiet ones can never be pushed into clipping.

### The source tag stays on the real app
The "♪ App ·" tag tells you which app the audio comes from. In live testing it once
blamed **"Live Captions"** — a captioning tool, never the actual media. Caption and
speech utility processes are now excluded from source naming, so the tag stays on
the real source: the game, the browser tab, the player.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
