## Tempo 1.0.240

**Clicker polish + a refreshed website**

Clicker
- **Fixed the clipped "CPS Test" button.** Its label was showing as "CPS Tes" — the
  button is now sized for the gauge icon plus the full word, so it reads "CPS Test".
- **Active CPS preset is highlighted.** The preset (10 / 50 / 100 / 200) that matches
  your current rate is now filled in the accent colour, so you can see at a glance which
  one is active — and it follows along when you change the speed. It shows the right
  preset on startup too (it used to stay stuck on the first one).

Website
- The project site (`index.html`) was rewritten to be more detailed and a lot cooler:
  a **live theme switcher** (tap a colour and the whole page reskins, like the app),
  an interactive **"how fast can you click?" CPS meter**, a **click-modes** explainer
  (Interval / Hold / Burst), a **why-Tempo comparison** table, a top scroll-progress
  bar and a hero spotlight, plus expanded FAQ.

Cumulative — includes per-tab scroll memory (1.0.239), the blank-screen-on-restore fix
(1.0.238), the visual redesign (1.0.237) and everything before.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
