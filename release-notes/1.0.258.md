## Tempo 1.0.258

**Discord fix, captions that name the playing app, and a self-closing welcome note**

### Discord no longer shows you "playing Tempo" (the Steam game)
There's a Steam game literally called "Tempo" (publisher Aestronauts), and Discord's game
detection flags any program running from a path that ends in `tempo\tempo.exe` — which was
exactly where the installer put Tempo. Verified against Discord's own detectable-games
database.

The fix: Tempo now installs to **`%LOCALAPPDATA%\Programs\TempoClicker\Tempo.exe`**. The
exe keeps its name, so in-app updates, docs and checksums are all unchanged — only the
folder differs, which is what breaks Discord's match. Installing this version:
- moves Tempo to the new folder and **removes the old one** automatically,
- retargets the Start Menu shortcut,
- keeps your settings, profiles and macros exactly where they were (they live in AppData).

Running a **portable** copy from a folder you named "Tempo"? You'll get a one-time tray
hint suggesting a folder rename (e.g. "TempoClicker") — that's all it takes.

### The caption bar names what's playing
While audio plays, the caption line now starts with the app it comes from:

```
♪ YouTube  ·  Speaker 1: welcome back to the channel
♪ Roblox   ·  Speaker 2: follow me, the exit is this way
♪ VLC      ·  ♪ Music or sounds playing — no speech
```

Any app is identified from Windows' per-app audio sessions — known apps and sites get
their proper name, unknown ones show their window title. The name holds through natural
speech pauses so it doesn't blink on and off.

**Speaker numbering also resets when the app changes** — a new game or video means new
people, so Speaker 1 is always the first voice of what you're watching now, never a stale
match against the previous app's voices.

### The welcome note closes itself
The "Quick safety note" on launch now counts down on its button — **"Got it (10)" →
"(9)" → ...** — and closes by itself after 10 seconds. Click either link and the countdown
stops, so it never disappears while you're actually reading it.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
