## Tempo 1.0.238

**Fixed: the window coming back to a blank/empty screen**

When the window was restored — from the tray, the taskbar, or after macro recording
auto-minimised it — the page could come up **empty** and only fill in after a short
delay (it was waiting on a timer to "reload" the layout). That's fixed:

- **Instant repair.** The layout is now re-centred and **repainted immediately** on
  restore, so the content is there the moment the window reappears — no blank frame,
  no waiting for it to catch up.
- **Tray show fixed too.** Bringing the window back from the tray now repaints right
  away (previously a hidden-then-shown window could skip the repair entirely).
- **Flicker-free re-centring.** When the window is resized or maximised, the content is
  repositioned in a single batched pass instead of moving every control one-by-one, so
  it no longer flickers or momentarily blanks while centring.

Cumulative — includes the 1.0.237 visual redesign and everything before it.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
