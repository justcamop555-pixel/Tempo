## Tempo 1.0.235

**Clicker, Macros & Statistics — polished old features and a few new ones**

Clicker
- **New — "Set exact CPS".** The Manual Speed card now has a type-in box: enter an exact target rate (or press Enter / the Set button) and Tempo applies it instantly. It stays in sync with the slider, the ± buttons and the CPS presets, so the card always shows your current rate.

Macros
- **Nicer playback progress.** The playback progress bar is now the app's themed rounded bar (accent-coloured, follows your theme) instead of the old grey Windows bar — matching the session-goal and milestone bars. Live "Loop x/y • step n/m • ~time left" feedback is unchanged.

Statistics
- **New — quick goal buttons.** Set a session goal in one tap with the new 1K / 10K / 100K buttons, just like the Clicker's CPS presets (typing a custom number still works).
- **Richer "Copy summary".** The copied snapshot now also includes Today, Lifetime clicks and Best-CPS-ever.

Polish
- All new labels are translated into the 6 supported languages (and the existing "Presets (CPS):" caption is now translated too).
- Themed progress bars now re-colour correctly the moment you switch themes.

Cumulative — includes everything from 1.0.234 and earlier.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
