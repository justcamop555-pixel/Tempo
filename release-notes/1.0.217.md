## Tempo 1.0.217

**Tempo is now a truly portable single .exe that works anywhere, and the window always opens centered**
- Tempo.exe is now fully self-contained: the .NET runtime, the UI Automation assemblies (needed to read Windows Live Captions), AND the native speech-engine libraries are all bundled INSIDE the exe. You can move or copy Tempo.exe on its own to any folder and it just works - no loose DLLs required beside it. This fixes "it only works inside its publish folder": running the exe detached from its DLLs used to break loading (which also showed up as the Live Captions / CacheRequest failure).
- The window now opens centered on screen every time, instead of reopening at its last position or some stale spot. If you prefer it to remember where you left it, turn on "Remember window position" in Settings.
- Note: publish with a runtime (e.g. dotnet publish -r win-x64 -c Release) to get the single-file portable exe.

Windows may show "Unknown publisher" because the app isn't code-signed - click More info → Run anyway. It's safe.
