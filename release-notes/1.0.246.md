## Tempo 1.0.246

**Macro timing accuracy (WASD holds), a batch of bug fixes, and much lighter Live Captions**

### Macro playback / recording timing
- **Playback now follows an absolute timeline.** Previously each delay was slept "from now",
  so the time spent on every keystroke/step (the input call, the on-screen step highlight,
  loop overhead) was added on top of every delay and piled up — key-holds and the whole pace
  ran progressively LONGER than recorded, which stretched in-game movement. Playback now
  schedules against one monotonic clock: that per-step overhead is absorbed by the next wait
  instead of accumulating, so a recorded WASD hold plays back at its true length even over
  long or looping macros. (A catch-up cap prevents an input burst after a system hitch.)
- **Recording uses the real hardware event time.** Delays between key presses were measured
  when Tempo's hook callback happened to run, which is delayed while the UI is busy — that
  jitter was baked into the recorded hold length. Recording now timestamps each key/click
  from the OS event time, so the recorded durations match what you actually did.

### Bug fixes
- **Live Captions window could be left stuck off-screen.** Two fixes: (1) on exit, Tempo now
  waits for its caption reader to finish before restoring Windows' caption bar, so a late
  background read can't re-hide it after restore; (2) Tempo no longer memorises an off-screen
  position as the "restore" spot (e.g. after a previous crash), and clamps the restore to a
  visible location as a safety net.
- **Recorder no longer captures Tempo's own input.** If the auto-clicker or another macro was
  running while you recorded, Tempo's synthesised clicks/keys could get recorded into the new
  macro. Synthetic (injected) input is now ignored during recording — only your real input is
  captured.

### Live Captions (Windows 11)
- **Much cheaper to mirror.** Reading the caption text used to re-walk Windows' entire caption
  UI-Automation tree several times a second (many slow cross-process calls). It now re-reads
  just the one text element it already found, re-scanning only occasionally or when that element
  stops producing text, and polls a touch less often — far less CPU for the same captions.

Cumulative — includes the 1.0.245 game-input (scan-code + focus) fixes, the 1.0.244 wrong-page /
flicker fixes and everything before.
