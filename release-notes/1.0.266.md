## Tempo 1.0.266

**"Start Tempo when I sign in to Windows" now actually sticks on Windows 11**

Turning on *Settings → Startup & Window → "Launch Tempo when I sign in to Windows"* is
supposed to open Tempo quietly in the tray at every login. On Windows 11 that could
silently fail — this release fixes the real causes.

### It respects Windows' own Startup list
Windows 11's **Task Manager → Startup apps** (and Settings → Apps → Startup) can *disable*
a startup entry without removing it. Tempo used to ignore that hidden flag:

- the checkbox stayed ticked, but Tempo never launched at sign-in;
- re-ticking the box didn't help, because the disable flag was still set.

Now Tempo reads that flag properly:

- **The checkbox tells the truth.** If you switch Tempo off in Windows' Startup list, the
  checkbox turns itself off to match the next time Tempo runs.
- **Turning it back on works.** Ticking the box now clears Windows' disable flag, so Tempo
  really does launch again.

### It heals a vanished entry
If a system cleaner or antivirus strips Tempo's startup entry while you still have the
setting on, Tempo quietly re-creates it at the next launch — pointed at wherever the exe
lives now.

### It confirms the change
Toggling the checkbox now verifies the registry actually updated. On a locked-down or work
PC where the write is blocked, you get told — instead of the setting silently doing nothing.

Together with the earlier fixes (the entry points at the real single-file exe, not a temp
folder, and auto-migrates when Tempo moves), "start with Windows" now survives folder
moves, cleaners, **and** Windows' own Startup toggle.

Verified end-to-end: a simulated Task-Manager disable flipped the checkbox off on the next
launch; re-enabling it cleared the flag and restored the entry.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
