## Tempo 1.0.251

**Sidebar & loading rework, a CPS-test keyboard mode, and a layout tidy-up**

### Sidebar & loading
- The **sidebar** now has a subtle version footer ("Tempo v1.0.251") with a divider, so the
  navigation rail reads as finished instead of trailing off into empty space.
- The **startup splash** gained a soft accent-tinted radial glow behind the logo, giving the
  loading screen more depth.

### Clicker / CPS Test
- The **CPS Test** now has a **keyboard mode**. Pick "⌨ Space" from the Input row and it
  measures how fast you can tap the spacebar (holding it down doesn't inflate the count — the
  OS auto-repeat is ignored, so only real presses register). It pairs with the Clicker's
  keyboard auto-presser added earlier, and keeps all the existing stats: CPS, peak-in-1s,
  consistency, fastest gap and the per-session tally.

### Layout
- Fixed the last **"Rep"** column in the Multi-Point points table being clipped at the right
  edge once the list had enough rows to scroll.
- I went through every tab and the CPS-test dialog looking for overlapping text or labels —
  none were found, so beyond that one column fix the layout is clean.
