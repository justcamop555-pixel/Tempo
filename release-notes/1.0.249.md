## Tempo 1.0.249

**Statistics accuracy + Clicker progress polish — improving existing features**

### Statistics — accurate all-time insights
Tempo keeps the last 200 clicking sessions in its history. The "all-time" insight cards were
recomputed from that window, so once you passed 200 recorded runs the oldest ones dropped out
and cards like **Active days**, **Longest streak**, **Best day**, **This year**, **Busiest
weekday/hour** and **Top profile** quietly started under-counting (and could even go *down*
over time).

Now those cards are backed by **rolling aggregates that Tempo keeps as you go**, so they stay
correct no matter how many sessions you rack up. When you update, Tempo seeds them once from
your existing history — nothing resets. (The by-session, last-7-days and by-hour **charts**
still show your recent history, which is what they're for.)

### Clicker — better run progress
- A **fixed-count** run now shows a live time estimate from how fast it's actually clicking:
  "▸ 340 / 1,000 (34%) · ~8s left".
- A **fixed-duration** run now shows the percentage alongside the remaining time.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
