## Tempo 1.0.250

**Macro pre-record countdown + Statistics summary polish**

### Macros — record countdown
The Record card now has an optional **"Countdown (s, 0 = off)"**. Set it to, say, 3 and Tempo
shows a 3, 2, 1 countdown before recording actually begins — giving you time to switch to the
game or app you want to record. The countdown's own window switch is *not* captured, so your
recording starts clean. It mirrors the countdown that playback already has. Default is 0
(start immediately).

### Statistics — fuller summaries
- **Copy summary** now also includes Active days, Best day and Busiest weekday.
- **CSV export** also includes Best day.

These build on 1.0.249's all-time-stats accuracy fix, so those values are correct even with
hundreds of recorded sessions.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
