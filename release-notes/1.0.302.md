## Tempo 1.0.302

**One more stutter class cleaned from captions**

### "…on the new build. new build" — gone
Watching the caption bar during testing showed one remaining stutter pattern: the
engine occasionally re-emits a short phrase right after closing a sentence —
"…on the new build. **new build**".

The repeat-collapser used to ignore all 2-word repeats on purpose, so that natural
speech like "I know, I know" always comes through as spoken. It now collapses a
2-word repeat in exactly ONE case: when the first copy ends a sentence (". ! ?") —
which is the stutter's signature, not how people talk. Comma-joined and
unpunctuated doubles still pass through untouched.

### Long-session check
The logs show caption sessions running for hours, so this release also audited the
long-run memory behaviour: the caption history and the rolling caption line are both
properly bounded. Nothing to fix — captions can run all day.
