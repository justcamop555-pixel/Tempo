## Tempo 1.0.232

**Fuller translations — far fewer texts stay in English**
- When you pick a non-English language, a lot more of the interface is now actually translated. Around **65 strings** that used to stay English in every language now have proper translations in **Spanish, French, German, Italian and Portuguese**:
  - Many **Settings** checkboxes (record history, on-screen overlay, write a log file, sleep in tray, remember window size, launch at sign-in, notify when a fixed run finishes, cursor trail…).
  - **Labels** like Header / Footer / Window, Font / Colour / Text size, Hold each click, Dwell, Opacity, Listen to, Caption source / model.
  - **Buttons** like Start / Stop / Pause / Resume, OK / Cancel / Close / Clear, Got it, Download model, Reset stats, Reset window position, Back up all data, Open models / log folder.
  - The privacy note and the **Multi-Point / Keybinds / Macros help paragraphs** at the top of those tabs.
- **No new languages were added** — this just fills the gaps in the six languages Tempo already ships. Verified by switching to Español: the whole window reads in the chosen language. (Proper names — theme names, font names, "Live Captions", "GitHub", "CPS" — are left untranslated on purpose. Language still applies after a quick restart.)

Cumulative — includes the 1.0.231 scroll-bar/title-bar work and everything before it.
