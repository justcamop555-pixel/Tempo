## Tempo 1.0.298

**Overlays stay on top of fullscreen games/video · Live Debug tells you what's wrong · the new features now speak all 5 languages**

### Overlays no longer vanish over fullscreen

The clicking badge, the countdown, the caption bar and the other overlays used to get
buried the instant a game or a fullscreen YouTube tab took over the screen.

A shared keeper now re-asserts every overlay the moment any other app takes the
foreground — the exact instant they'd otherwise be pushed underneath — backed up by a
fast timer for apps that keep re-topping themselves. So they stay visible over
**borderless-fullscreen games and fullscreen browser video**.

The honest limit: a program in **true exclusive fullscreen** (old-style DirectX
exclusive mode) owns the whole display, and no ordinary window — Tempo's or any other
overlay tool's — can draw over it. Run the game in **borderless / windowed-fullscreen**
mode and this covers it. Verified by checking the real Windows z-order against a
fullscreen top-most window.

### Live Debug now leads with a Health panel

Instead of scrolling the event log, the top of Live Debug answers **"is anything wrong
right now?"** at a glance:

- **Green** `✓ no issues detected` when all is well.
- **Amber / red** otherwise, naming each problem in plain English: the **last error**
  (with how long ago), a GPU setting that needs a restart, an auto-downgraded speech
  model, captions falling behind live audio, **hotkeys Windows wouldn't reserve**,
  startup **blocked in Task Manager**, camera movement **armed globally**, anti-freeze
  throttling.

Errors and warnings are now captured with their real underlying cause, so they surface
here instead of being swallowed silently.

### All five languages caught up

Everything added recently — the overlay **Customise…** dialog, the start-delay + beep,
the update-frequency picker, the startup delay, and the whole **camera-relative
movement** card — was English-only in Español, Français, Deutsch, Italiano and
Português. It's now translated across all five (verified live in Spanish). Longer help
text still falls back to English, as it always has.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
