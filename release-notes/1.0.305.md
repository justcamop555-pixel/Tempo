## Tempo 1.0.305

**The Rainbow Six freeze fix — game mode goes from "easing off" to "hands off"**

### The freeze, found and fixed
Reported live: playing Rainbow Six with captions on, the game sometimes froze
entirely. The logs from that session told the story:

1. **The face analyser was still touching the game.** Even in 1.0.304's
   low-impact mode it captured the game window once a second — and the Windows
   call it uses (PrintWindow) forces the game to render an extra copy of itself
   **synchronously**. A game that isn't pumping messages mid-frame can stall on
   that call for whole seconds. Fixed properly: during a fullscreen game, face
   analysis now **pauses completely** — not one capture touches the game window,
   at any rate. Speaker labels fall back to voice matching (the primary signal
   anyway), and face analysis resumes the moment the game closes. Both
   transitions log.

2. **Game mode was flapping.** Real play breaks the fullscreen signature
   constantly — loading screens, overlays, popups — and the log shows game mode
   entering and exiting as fast as **every 2 seconds** mid-match. Every flap
   rebuilt the speech decoder and restarted window captures. Leaving game mode
   now requires ~6 seconds of stable non-fullscreen; a stray blip changes
   nothing. Entering stays immediate — protecting the game matters more than a
   false positive. Verified live: a deliberate 3-second interruption produced
   zero transitions.

3. **The overlay keeper was churning.** The always-on-top backstop re-asserted
   every overlay 4× a second; z-order churn above a fullscreen game bounces DWM
   out of its fast presentation path. During game mode the backstop relaxes to
   ~1.5 s — while the instant foreground-event re-top (the thing that actually
   keeps captions visible over a game) stays instant.

4. **No model swaps mid-match.** A game hogging the GPU makes inference look
   slow, and the too-slow ladder used to respond by hot-loading a smaller model
   file — hundreds of MB, mid-firefight, to fix slowness the game was causing.
   The ladder now holds while a game is on screen and judges honestly afterwards.

### Honest lag advice
The "engine is behind live audio" warning used to suggest "a smaller model, or
the GPU engine" even when a game owned the GPU and no setting was at fault.
During game mode it now says what's true: the game has the hardware right now —
normal during play; captions catch up between fights.

Windows may show "Unknown publisher" because the app isn't code-signed — click More info → Run anyway. It's safe.
